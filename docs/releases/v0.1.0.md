## Hugging Face config-metadata repair

The first custom Dataset Card renderer replaced Hugging Face's generated README front matter without preserving the `configs` section. The Parquet data for both named configs remained on the Hub, but `load_dataset("saeeew/JP-HomophoneBench", "homophone8")` could not discover the named config and reported only `default`.

The publisher was corrected so that after `DatasetDict.push_to_hub(config_name=...)` it enumerates the Hub's Parquet shards and reconstructs README `configs` metadata for every existing named configuration before replacing the Dataset Card.

Metadata-repair publication run: `33451484908` — completed successfully.

## Final workflow policy

After verifying both publication paths and the config-metadata repair, `.github/workflows/jp-homophone-hf-publish.yml` is `workflow_dispatch` only. Its defaults are:

- repo: `saeeew/JP-HomophoneBench`
- config: `homophone8`
- license policy: `permissive`
- private: `false`

Selecting `license_policy=research` with a distinct config such as `homophone8-research` includes NonCommercial-derived rows and must be treated according to their upstream license.
